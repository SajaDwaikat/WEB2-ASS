# Pomodoro Timer App

A simple Pomodoro Timer application built with JavaScript ES Modules and Webpack.

## Features

- Work and Break timer modes with customizable durations
- Long breaks after four work sessions
- Sound notifications when sessions end
- Clean, responsive UI

## Technologies Used

- JavaScript ES Modules
- Webpack for bundling
- CSS for styling

## Project Structure

The application is organized into several modules:

- `timer.js`: Core timer logic and state management
- `ui.js`: DOM manipulation and display updates
- `settings.js`: User preferences and validation
- `notifications.js`: Sound alerts and browser notifications
- `index.js`: Main entry point that connects all modules
